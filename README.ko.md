# Mac OS 27 Finder Bar

[English](README.md) | [Português](README.pt-BR.md) | **한국어**

Windows 11 화면 상단에 macOS 27 스타일의 메뉴 막대를 추가하는 [Windhawk](https://windhawk.net) 모드입니다. 왼쪽에는 최상위 앱의 메뉴가, 오른쪽에는 시스템 상태, 제어 센터, 알림 및 시계가 실시간 유리 효과로 표시됩니다.

## 주요 기능

- **전역 메뉴**: 최상위 앱의 메뉴를 막대에 표시합니다. 기존 Win32 앱은 실제 메뉴를 보여 주고, 최신 앱은 메뉴 막대가 있으면 UI Automation으로 표시하며, 브라우저, 파일 탐색기, Office, VS Code 등은 앱 자체의 단축키를 보내는 기본 제공 메뉴를 사용합니다. **윈도우** 메뉴에는 앱의 열린 윈도우가 나열되고, **도움말**에서는 앱의 모든 메뉴를 검색할 수 있습니다
- **로고 메뉴**: 이 PC에 관하여, 시스템 설정, Microsoft Store(대기 중인 업데이트 수 표시), 강제 종료, 잠자기, 최대 절전, 다시 시작, 시스템 종료, 화면 잠금, 로그아웃
- **상태 아이콘**: 배터리, Wi-Fi, Bluetooth, 사운드(스크롤로 볼륨 조절), 디스플레이, 키보드 레이아웃, 지금 재생 중(곡 이름이 길면 흐르며, 큰 커버 또는 컴팩트 패널에 선, 컬러 선 또는 물결 모양의 진행 막대 표시), 집중 모드, 마이크 및 카메라(사용 중에는 아이콘이 주황색과 초록색으로 바뀌며, 클릭하면 사용 중인 앱을 확인하고 마이크를 음소거할 수 있음), 날씨, 검색(Windows 검색 또는 Siri Plus Launchpad). 들어가지 않는 아이콘은 화살표로 접히며, 각 아이콘은 켜거나 끌 수 있습니다
- **제어 센터**: Wi-Fi, Bluetooth, 미디어, 다크 모드, 방해 금지 모드, 밝기, 사운드 및 출력, 그리고 추가할 수 있는 타일: 야간 모드, 비행기 모드, 화면 캡처, 화면 기록, 전원 모드 및 전원 계획, 저전력 모드(한 번 클릭으로 켜고 끄기), 돋보기, 화면 잠금, 계산기, 작업 관리자, 이모티콘, 데스크탑 보기. **제어 항목 편집**으로 타일을 추가, 제거, 이동 및 크기 조절할 수 있습니다. 전원 모드에서는 Windows 11 모드와 전원 계획(중복된 계획은 숨김)이 있는 상자가 열립니다. 이름이 길어 들어가지 않는 타일은 마우스를 올리면 이름이 흐릅니다. 타일은 알약형 또는 둥근 사각형으로 설정할 수 있습니다
- **알림 알약**: 헤드폰, 오디오 출력, 배터리 부족, 충전기, 집중 모드, Caps Lock, USB 기기 및 드라이브, 완료된 다운로드, 복사 및 오려두기, 화면 캡처, 화면 기록, Windows 알림이 막대에서 내려오는 유리 알약으로 표시되며(조작할 수 있는 알림은 더 오래 표시되고 벨 패널로 이동), 볼륨, 밝기 및 Bluetooth용 플로팅 알약도 있습니다. 스타일(유리, 리퀴드 글래스 또는 어둡게), 크기, 위치, 표시 시간 및 애니메이션을 설정할 수 있습니다
- **알림** (**메뉴 막대 설정…** → **알림 알약**에서 *Windows 알림*을 켜십시오): 앱 알림이 알약과 벨 패널에 앱별로 묶여 표시됩니다. 앱이 지원하면 알약에서 바로 메시지(예: WhatsApp)에 **답장**할 수 있고, 알림을 옆으로 **드래그**하여 지울 수 있으며, 원하면 **막대에만** 알림이 표시되도록 할 수 있습니다(막대가 알림을 표시하는 동안 Windows 배너는 화면 밖으로 이동)
- **캘린더**: 시계를 클릭하면 캘린더와 내 .ics 파일의 일정이 표시됩니다(로컬에서만 읽으며 다운로드하지 않음). 설정에서 바로 가져올 수 있습니다
- **날씨**: 막대에 온도를 표시하고 예보가 있는 유리 위젯을 제공합니다(Open-Meteo, MET Norway 또는 wttr.in, 계정 불필요)
- **실시간 유리**: 막대와 패널이 뒤에 있는 내용을 실시간으로 흐리게 처리하며, 가장자리 굴절이 있는 실험적인 리퀴드 글래스를 제공합니다(기본값: 켬)
- **막대와 메뉴**: 투명(기본값), 블러 유리 또는 리퀴드 글래스 막대, 앱이 최대화되면 불투명. 메뉴는 자체 반투명 유리 또는 제어 센터와 같은 유리를 사용할 수 있으며, 라이트, 다크 또는 자동 테마, 아홉 가지 선택 색상, 글꼴과 크기를 설정할 수 있습니다. 전체 화면 앱에서는 가려지고, 자동 가리기 옵션이 있으며, 모든 모니터를 지원합니다
- **설정 윈도우**: 로고 → **메뉴 막대 설정…**에서 macOS 스타일 윈도우로 설정을 열 수 있으며, 검색을 지원하고 막대를 다시 시작하지 않고 즉시 적용됩니다
- **언어**: Windows 표시 언어를 따르거나 직접 선택할 수 있습니다(영어, 포르투갈어, 스페인어, 프랑스어, 독일어, 이탈리아어, 중국어 간체 및 한국어)

## 설치

1. [Windhawk](https://windhawk.net)를 설치합니다.
2. Windhawk의 모드 카탈로그에서 **Mac OS 27 Finder Bar**를 검색하고 **Install**을 클릭합니다.

카탈로그에 등록되기 전에 이 저장소의 버전을 사용해 보려면: Windhawk에서 **Create a new mod**를 클릭하고 코드를 [`mac-os-27-finder-bar.wh.cpp`](mac-os-27-finder-bar.wh.cpp)의 내용으로 바꾼 다음 **Compile Mod**를 클릭하고 **Exit Editing Mode**를 클릭합니다.

## 설정

설정은 모드 자체 윈도우(로고 메뉴 → **메뉴 막대 설정…**)에 있으며 즉시 적용됩니다. Windhawk의 모드 설정 페이지에는 윈도우에 없는 몇 가지 항목이 있습니다. 글꼴, 유리 색조, 테마, 데스크탑에 표시되는 이름, 기본 제공 메뉴, 제어 센터 타일 모양, 열기 애니메이션, 트레이 클릭, 앱 업데이트 수, .ics 파일 경로, 그리고 막대가 표시되지 않을 때 윈도우의 옵션을 기본값으로 되돌리는 **막대 설정 복원**입니다.

## Windows 설정을 변경하는 항목

일부 제어 센터 타일과 메뉴 항목은 Windows 자체 빠른 설정이 바꾸는 것과 같은 실제 Windows 설정을 변경하며, 모드를 꺼도 변경된 상태로 유지됩니다. 다크 모드(앱과 시스템 테마를 같은 값으로 설정), 야간 모드, 전원 모드 및 전원 계획(전원 모드를 바꾸면 계획도 균형으로 전환됨), 저전력 모드, 방해 금지 모드, 밝기, 기본 오디오 기기, 볼륨 및 음소거, 마이크 음소거, Wi-Fi 및 Bluetooth 무선, Wi-Fi 네트워크, 디스플레이 모드가 해당합니다. 해당 타일이나 항목을 클릭하지 않으면 아무것도 바뀌지 않습니다.

## 네트워크 사용

모드는 직접 설정한 기능에 대해서만 온라인에 접속합니다(캘린더는 로컬 .ics 파일만 읽음).

- **날씨**: 장소를 선택한 후에 사용됩니다. OpenStreetMap Nominatim 또는 Open-Meteo로 장소를 검색하고, 선택한 서비스(Open-Meteo, MET Norway 또는 wttr.in)에서 예보를 받으며, 이때 장소의 좌표는 약 1km 단위로 반올림됩니다. 날씨 아이콘을 끄면 모든 요청이 중단됩니다.
- **앱 업데이트 수**(기본값: 끔, Windhawk 설정): `winget upgrade`를 실행하며, 이는 winget의 소스를 온라인으로 확인합니다. 모드는 winget의 소스 계약에 대신 동의하지 않습니다. Windows 업데이트 수는 오프라인으로 확인합니다.

복사 알약은 "복사됨" 또는 "오려둠"만 표시하며, 무엇을 복사했는지는 절대 보여 주지 않고 앱이 비공개로 표시한 항목(암호 관리자 등)은 Windows 클립보드 기록과 마찬가지로 건너뜁니다.

## 작동 방식

막대는 자체 Windhawk 프로세스(작업 관리자에는 Windhawk로 표시)에서 실행되므로 문제가 생겨도 작업 표시줄과 데스크탑은 계속 작동합니다. 탐색기에는 트레이 아이콘의 등록 정보를 막대로 복사하는 작은 후크만 남습니다. 해당 프로세스를 수동으로 종료했다면 Windhawk에서 모드를 껐다가 다시 켜서 막대를 되살리십시오.

## 알려진 제한 사항

- 기존 메뉴 막대가 없는 앱은 키보드 단축키 기반의 기본 제공 메뉴를 사용합니다.
- Bluetooth는 기존(BLE가 아닌) 기기를 나열하며, 연결 및 연결 해제는 설정을 열어서 진행합니다.
- 전원 모드와 저전력 모드는 문서화되지 않은 Windows 함수를 사용합니다. Windows가 거부하면 타일이 해당 설정 페이지를 엽니다.
- 화면 기록은 Win+Shift+R을 사용하며 최신 캡처 도구가 필요합니다.
- 알약에서의 답장은 Windows에 알림 활성화 프로그램을 등록하는 앱에서 작동하며, 그렇지 않으면 알약이 앱을 열고 입력한 텍스트를 복사합니다.
- 실시간 유리(및 막대의 리퀴드 배경)를 사용하면 막대와 패널이 스크린샷에 나타나지 않습니다.
- Windhawk 자체가 관리자 권한으로 실행되는 경우(권한 상승으로 시작된 포터블 모드) 막대에 트레이 아이콘이 표시되지 않습니다. 셸의 트레이 데이터를 권한 상승된 막대에 전달하면 모든 앱이 가짜 아이콘을 보낼 수도 있기 때문입니다.
